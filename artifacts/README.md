# Артефакты ВКР

Тема: **«Разработка информационной системы учёта заявок на обслуживание клиентов»**

Папка содержит проектные артефакты, подготовленные на этапе планирования ВКР. Структура соответствует ГОСТ 34.601 (стадии создания АС) и согласуется с НИР, защищённой ранее.

## Структура

```
artifacts/
├── 01_skeleton/                  # Шаг 1: каркас ВКР
│   └── ВКР_скелет.docx           # титул + оглавление (TOC) + введение + 4 главы + приложения
├── 02_database/                  # Шаг 2: модель данных
│   ├── er_diagram.puml           # концептуальная ER-диаграмма (PlantUML)
│   ├── datalogical_schema.md     # описание таблиц, типов, индексов, FSM
│   └── schema.sql                # рабочий DDL для PostgreSQL 15+ с триггерами и seed
├── 03_diagrams/                  # Шаг 3: UML и BPMN
│   ├── use_case.puml             # 5 акторов, 20 use cases в 5 пакетах
│   ├── bpmn_as_is.puml           # текущий процесс (до внедрения)
│   ├── bpmn_to_be.puml           # целевой процесс (после внедрения)
│   ├── activity_request_lifecycle.puml  # машина состояний заявки
│   └── README.md                 # инструкции по рендеру + Mermaid-копии
├── 04_tz/                        # Шаг 4: техническое задание
│   └── ТЗ_ГОСТ_34.602.docx       # ТЗ по ГОСТ 34.602-2020 (9 разделов, 5 таблиц)
└── _tools/                       # генераторы DOCX (служебные)
    ├── docx_builder.py
    ├── build_skeleton.py
    └── build_tz.py
```

## Как открыть и использовать

| Артефакт | Что делать |
|---|---|
| `ВКР_скелет.docx` | Открыть в Word, нажать F9 на оглавлении — оно подтянется автоматически. Заполнять главы поверх уже подготовленной структуры. |
| `ТЗ_ГОСТ_34.602.docx` | Аналогично. Согласовать с научным руководителем, подписать. Использовать как Приложение А в ВКР. |
| `*.puml` | Скопировать в https://www.plantuml.com/plantuml/uml для рендера в PNG/SVG. Альтернатива — VS Code + расширение PlantUML. |
| `*.md` (включая раздел Mermaid в `03_diagrams/README.md`) | Открыть прямо в GitHub — диаграммы Mermaid отрисуются автоматически. |
| `schema.sql` | Загрузить в PostgreSQL 15+ командой `psql -f schema.sql`. Будут созданы все таблицы, индексы, триггеры и базовые справочники. |

## Что осталось сделать

1. **Прототип системы** — следующий крупный этап. Стек: Python 3.11+ / Django 5 / DRF / PostgreSQL 15 / React 18 / Ant Design / Celery+Redis / Docker. Будет реализован после согласования ТЗ.
2. **Макеты UI** (Figma) — параллельно с разработкой backend.
3. **Тестирование** — pytest + Locust для нагрузочных проверок.
4. **Расчёт экономической эффективности** — на основе данных тестового внедрения.
