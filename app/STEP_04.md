# Шаг 4. Отчёты и дашборд для менеджера

## Что появилось

### Бизнес-логика
- **`core/reports.py`** — расчётный слой:
  - `report_by_period(date_from, date_to)` — динамика создания / закрытия по дням;
  - `report_executors()` — нагрузка исполнителей с агрегатами Avg/Count и просрочкой;
  - `report_sla()` — соблюдение SLA по приоритетам (`closed_at <= due_date`);
  - `live_dashboard_metrics()` — метрики реального времени.
- **`core/permissions.py`** — добавлена функция `can_view_reports(user)`.
  Раздел доступен только админу и менеджеру.

### Новые маршруты
- `/reports/` — индекс с живыми метриками и тремя карточками-ссылками;
- `/reports/by-period/` — динамика по дням с графиком Chart.js;
- `/reports/by-period.csv` — экспорт в CSV;
- `/reports/executors/` — загрузка исполнителей;
- `/reports/executors.csv`;
- `/reports/sla/` — соблюдение SLA;
- `/reports/sla.csv`.

### Шаблоны
- `core/reports/index.html` — главная отчётов с метриками.
- `core/reports/by_period.html` — таблица + Chart.js bar-chart.
- `core/reports/executors.html` — таблица загрузки.
- `core/reports/sla.html` — таблица с цветовыми бейджами по проценту соблюдения SLA.

### Шапка
- Пункт «Отчёты» **появляется только у менеджера и админа**
  (исполнитель и оператор его не видят).
- При попытке зайти под ролью без прав — `403 Forbidden`.

## Применение

```powershell
git pull
python manage.py runserver
```

Миграций нет — модели не менялись.

## Что проверить

### Под `manager` / `demo1234`
1. В шапке появилась активная ссылка **«Отчёты»**.
2. На главной отчётов:
   - 3 карточки метрик (открытых, просрочено, без исполнителя);
   - 2 таблицы (открытые по статусам и по приоритетам);
   - 3 карточки-ссылки на подробные отчёты.
3. Открываете «Динамика по периоду» — bar-chart по 30 дням, таблица под ним,
   фильтры по датам, кнопка «Скачать CSV». Откройте CSV в Excel — кириллица
   в порядке (BOM выставлен).
4. «Загрузка исполнителей» — таблица с цифрами по каждому,
   подсветка просрочки красным.
5. «Соблюдение SLA» — карточки сводки + таблица по приоритетам с
   зелёным/жёлтым/красным бейджем (≥95% / ≥80% / иначе).

### Под `executor1` / `demo1234`
1. В шапке **нет** пункта «Отчёты».
2. Если ввести `/reports/` в адресной строке вручную — увидите
   «Раздел отчётов доступен только менеджеру и администратору» (403).
   Это нормальное и правильное поведение RBAC.
