# Шаг 2. Аутентификация и навигация

## Что появилось

- **`templates/registration/login.html`** — кастомная страница входа на Bootstrap.
  Содержит подсказку с тестовыми учётками (только в DEBUG-режиме).
- **`templates/registration/password_change_form.html`** и
  **`password_change_done.html`** — стилизованные страницы смены пароля.
- **`templates/base.html`** — обновлён:
  - навигационная шапка с пунктами Главная / Заявки / Клиенты / Отчёты / Админка;
  - выпадающее меню профиля справа (роль, email, смена пароля, выход);
  - Bootstrap Icons для красивых иконок;
  - sticky-footer (подвал прижат к низу).
- **`core/views.py`** — главная страница защищена `@login_required`,
  переписана под небольшой дашборд с карточками-метриками,
  распределением по статусам и блоком «мои заявки».
- **`core/templates/core/home.html`** — новый дашборд.

## Применение

```powershell
git pull
# ничего пересоздавать не нужно: моделей не меняли, миграции не нужны
python manage.py runserver
```

## Что проверить

1. Откройте http://127.0.0.1:8000/ — если вы не вошли, редирект на
   `/accounts/login/?next=/`. Появится подсказка «Для доступа к этой
   странице нужно войти».
2. На странице входа в DEBUG-режиме видна шпаргалка с тестовыми учётками.
   Войдите, например, как `executor1` / `demo1234` — увидите дашборд
   с реальными цифрами и блоком «мои заявки» (для executor1 там должны
   быть несколько строк, для admin — пусто, потому что admin не
   является исполнителем ни одной заявки).
3. В правом верхнем углу — выпадающее меню с ФИО, ролью, email,
   ссылкой смены пароля и кнопкой выхода.
4. Зайдите как разные роли (`manager`, `operator`, `executor2`),
   посмотрите, как меняется блок «мои заявки» и значок роли.
5. Кнопка «Админка» в шапке появляется только у пользователей с
   `is_staff=True` (admin, manager, operator).
6. После выхода вы попадаете на /, который снова просит войти —
   круг замкнулся, сессия снята.

## Что прислать в ответ

- ✅ Скриншот страницы входа с подсказкой.
- ✅ Скриншот дашборда после входа (любой ролью, лучше `executor1` —
  у него есть заявки в блоке «мои заявки»).
- ✅ Скриншот выпадающего меню профиля.
- Сообщение **«Шаг 2 готов»** — двинусь к Шагу 3
  (страницы списка заявок, фильтры, карточка заявки).
